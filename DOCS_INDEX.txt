================================================================================
INSTALLASI CEPAT
================================================================================

1. Install Node.js dari https://nodejs.org
2. Install PostgreSQL dari https://www.postgresql.org/download/
   (Windows: installer EDB, ingat password user postgres)
3. Verifikasi server jalan: pg_isready (harusnya: accepting connections)

Backend (otomatis buat database + impor skema):
cd backend
npm install
copy .env.example .env
# Edit .env: isi DB_PASSWORD (password postgres) dan JWT_SECRET
npm run db:setup
npm start

Frontend:
cd frontend
npm install
npm start

Akses: http://localhost:3000
Login pertama: ADMIN001 + SUPERADMIN_SETUP_PASSWORD (lihat backend/.env.example)

================================================================================
SKEMA DATABASE
================================================================================

Main Tables:
- users (All user accounts)
- prestasi (Achievements)
- organisasi (Organizations)
- event (Events)
- pelanggaran (Violations)
- perilaku (Behavior)
- ipt_history (IPT change log)
- approvals (Approval workflow)
- permissions (Access control)

Fields utama:
- users: id, nama, role, kelas, grha, ipt_total, ipt_awal
- prestasi: user_id, jenis, tingkat, peringkat, point, status
- approvals: user_id, jenis, data, pembina_status, superadmin_status

================================================================================
ALUR KERJA SISTEM
================================================================================

1. LOGIN FLOW:
   User -> Enter credentials -> JWT validation -> Redirect to dashboard

2. DATA INPUT FLOW:
   Select input type -> Select student -> Fill form -> Upload bukti
   -> Submit -> Pending -> Approval -> IPT update

3. APPROVAL FLOW (satu tingkat - superadmin saja):
   Pending -> Superadmin review (menu Approvals) -> (Approve/Reject + alasan)
   -> Apply changes -> Update IPT -> Log history -> Notify user
   Input langsung superadmin otomatis approved tanpa antrean.

4. IPT CALCULATION:
   Base: 80 -> Add/subtract points -> Save to DB
   -> Create history -> Update leaderboard
   (Tidak ada batas 0-100; nilai boleh negatif. Batas minimum per
   tingkat X/XI/XII diatur di Konfigurasi IPT.)
